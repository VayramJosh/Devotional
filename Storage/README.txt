STORAGE
This is the "storage" folder for the site. Your posts (posts.json) and audio files are saved here
automatically every time you upload from admin.html. You never have to choose a folder.

Online, "storage" lives inside Netlify (a built-in store named "storage"), because a live website
can't write into its own files. You can see it in Netlify: your site > Blobs (or Storage).
This local folder is just a placeholder so the name is in your project.
